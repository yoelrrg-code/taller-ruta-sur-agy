# Interview Input Directory

Drop the client/project interview file here after cloning this boilerplate:

- **Transcripts**: `.txt`, `.md`, `.vtt`, `.srt`, `.json`
- **Audio / Video recordings**: `.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`, `.aac`, `.webm`, `.mp4`

Then ask your AI agent to run the `interview-to-agents` skill to:
1. Transcribe the recording (if audio/video is provided).
2. Extract all project, brand, design, content, and SEO requirements.
3. Auto-generate any missing details marked with `SUGERIDO_POR_IA`.
4. Populate `AGENTS.md` at the repository root.
